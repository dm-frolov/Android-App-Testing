# 📱 Android App Testing (Mobile QA)

Комплексное тестирование мобильного приложения **Shopping List**.

---

## 📌 О проекте

В рамках практического обучения я провел полное тестирование Android-приложения для управления списком покупок/задач. В ходе работы были созданы все виды тестовой документации и выявлены критические дефекты валидации.

**Тестируемое приложение:** Shopping List APK  
**Платформа:** Android  
**Версия приложения:** 1.0

---

## 🎯 Цель тестирования

Проверка функциональности приложения, корректности валидации данных, UX/UI и стабильности работы в различных сценариях использования.

---

##  Объем тестирования

### Функциональные модули:

✅ **Создание задач:**
- Ввод текста (валидация кириллицы)
- Проверка лимита символов (макс. 25 символов)
- Проверка лимита количества задач (макс. 10)
- Валидация пустых значений

✅ **Редактирование задач:**
- Долгое нажатие для входа в режим редактирования
- Изменение текста задачи
- Отмена изменений
- Валидация при сохранении

✅ **Отображение задач:**
- Корректное отображение списка
- Перенос длинного текста
- Сохранение состояния после закрытия
- Отметка выполненных задач

✅ **UX/UI и мобильная специфика:**
- Адаптация под ориентацию экрана (портретная/альбомная)
- Работа с виртуальной клавиатурой
- Сворачивание/разворачивание приложения
- Обработка прерываний (входящие звонки)

---

## 🧪 Типы примененного тестирования

### 1. **Functional Testing**
- Проверка создания, редактирования, удаления задач
- Валидация полей ввода (кириллица, длина текста)
- Проверка бизнес-логики (лимит 10 задач)

### 2. **Negative Testing**
- Ввод латиницы вместо кириллицы ❌
- Ввод цифр в поле задачи ❌
- Ввод пустых значений (только пробелы) ❌
- Превышение лимита символов (26+ символов) ❌

### 3. **Validation Testing**
- Проверка сообщений об ошибках
- Корректность валидации на кириллицу
- Проверка граничных значений (7 символов, 25 символов)

### 4. **UI/UX Testing**
- Адаптивная верстка под разные экраны
- Читаемость текста (контраст, размер шрифта)
- Визуальная обратная связь при нажатии кнопок
- Корректность отображения клавиатуры

### 5. **Compatibility Testing**
- Портретная и альбомная ориентация
- Сохранение состояния при повороте экрана
- Отображение на разных разрешениях

### 6. **Interruption Testing**
- Сворачивание приложения во время ввода
- Переход в другое приложение
- Возврат к несохраненным данным

### 3. **Баг-репорты** (Bug Reports)
Оформленные отчеты о найденных дефектах в Jira:

#### **Найденные дефекты:**

**🐛 Bug #1: [ZUKX-12] Создание 11-й задачи при превышении лимита**
- **Приоритет:** Medium
- **Тип:** Bug
- **Описание:** Приложение позволяет создать 11 задач, хотя лимит установлен на 10
- **Ожидаемый результат:** Сообщение об ошибке "Нельзя создать более 10 задач"
- **Фактический результат:** Задача успешно создана

**🐛 Bug #2: [ZUKX-13] Изменение языка на латиницу в режиме редактирования**
- **Приоритет:** Medium
- **Тип:** Bug  
- **Описание:** В режиме редактирования можно изменить текст задачи с кириллицы на латиницу
- **Ожидаемый результат:** Сообщение об ошибке "Задача должна быть только на русском языке"
- **Фактический результат:** Текст успешно меняется на латиницу

**🐛 Bug #3: [ZUKX-14] Добавление цифр в название задачи в режиме редактирования**
- **Приоритет:** Medium
- **Тип:** Bug
- **Описание:** В режиме редактирования можно заменить текст на цифры
- **Ожидаемый результат:** Сообщение об ошибке "Задача должна быть только на русском языке"
- **Фактический результат:** Цифры успешно добавляются
